# 4K Streaming Bandwidth Calculator

A free browser-based tool for estimating the internet bandwidth required for SD, HD, Full HD and 4K streaming across multiple simultaneous devices.

## Live Calculator

Try the live tool here:

https://mrrhabiri.github.io/4k-streaming-bandwidth-calculator/

## What it calculates

- Streaming quality: SD, HD, Full HD and 4K
- Number of simultaneous streams
- Additional household internet usage
- Optional safety margin for network stability

The calculator runs entirely in the browser and does not collect speed-test data.
